## 功能面事實

- **收藏夾批次整理／搬移**：grep 過，沒有。`registry/lib/components/video/quick-favorite/`（`displayName: '快速收藏'`）是單支影片頁面上的快速收藏按鈕（含快捷鍵、RBVP 相容外掛），效果等同 biliTidy 的「智慧收藏」單支往返，**不是批次整理/搬移**；`registry/lib/components/style/custom-navbar/favorites/`（`favorites.ts`／`favorites-folder.ts`／`FavoritesFolderSelect.vue`／`NavbarFavorites.vue`）只是把使用者的收藏夾清單顯示在自訂頂欄的下拉選單裡，方便快速跳轉，不涉及批次搬移或 AI 分類。沒有任何 AI/LLM 相關的分類邏輯或呼叫外部模型端點的程式碼。
- **批次取消關注／關注管理**：grep 過，沒有。搜尋 `relation/`、`unfollow`、`关注`、`attention` 只命中動態頁的「關注列表」篩選（`FollowingListSelect.vue`／`feeds/group-filter`）與訂閱時間顯示（`subscribe-time-show`），都是「讀取/篩選現有關注清單」的展示功能，沒有取消關注、批次操作或活躍度判斷邏輯。
- **B 站 API 風控與限速**：沒有集中的節流器或退避（backoff）邏輯。`src/core/ajax.ts`（291 行）只是 `XMLHttpRequest`／`GM_xmlhttpRequest` 的薄封裝＋`bilibiliApi()`（單純檢查 `code !== 0` 就 `throw`，不重試不退避）＋`getPages()`/`responsiveGetPages()`（用「5 個一批」的固定併發翻頁，同樣沒有延遲或退避）。grep `throttle`／`backoff`／`限速`／`限流`／`风控`／`-412`／`-352`／`-799` 在 `src`／`registry/lib` 裡除了 `lodash.throttle`（用於 UI 拖拽事件節流，與 API 請求無關）與圖示 SVG 的座標數字誤命中之外沒有任何結果，即專案沒有處理 B 站風控/限速的統一機制。
- **單一功能的安裝與啟用機制**：預設腳本安裝後**不預裝任何組件**（README 明講），使用者要在頁面左側的「設置面板」（`src/components/settings-panel/`）裡逐一啟用；每個功能是 `registry/lib/components/<category>/<name>/index.ts` 匯出的 `component`（`defineComponentMetadata` 定義的 metadata 物件），可獨立安裝/卸載/開關，也支援貼上外部連結安裝第三方組件（`registry/lib/docs/third-party.ts`）。沒有「功能開關」的設定檔案格式，狀態存在 Tampermonkey 的 `GM_setValue` 持久化儲存裡。
